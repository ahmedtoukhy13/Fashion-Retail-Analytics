# شرح مشروع Fashion Retail Analytics

## 1. فكرة المشروع

المشروع يحاكي متجر ملابس مصري يبيع من خلال الفروع والمتجر الإلكتروني خلال
عامي 2024 و2025. الهدف هو تجميع البيانات من مصادر مختلفة، تنظيفها، بناء نموذج
تحليلي، ثم عرض مؤشرات الأداء في Tableau.

المشروع تدريبي وليس نظامًا مستخدمًا داخل شركة حقيقية.

## 2. مسار البيانات

```text
CSV Files → Python → PostgreSQL Raw → SQL Cleaning → Analytics Views → Tableau
```

- **CSV:** ملفات البيانات الأصلية مثل المبيعات والعملاء والمنتجات.
- **Python:** يحمّل الملفات إلى قاعدة البيانات دون تعديل البيانات.
- **Raw Schema:** يحتفظ بالبيانات كما وصلت من المصدر.
- **Clean Schema:** ينظف الأخطاء والتكرار ويوحّد الصيغ.
- **Analytics Schema:** يجهز جداول مفهومة للتحليل.
- **Tableau:** يعرض النتائج في Dashboard تفاعلية.

## 3. لماذا استخدمت كل أداة؟

### Python

استخدمته لأتمتة تحميل ملفات CSV إلى PostgreSQL بدل استيراد كل ملف يدويًا.
Python هنا مسؤول عن **نقل البيانات فقط**، وليس التحليل.

### PostgreSQL وSQL

استخدمتهما لفحص جودة البيانات، تنظيفها، إزالة التكرارات، توحيد القيم، دمج
المبيعات، وحساب المقاييس المطلوبة للتحليل.

### Tableau

استخدمته لبناء الرسوم، مؤشرات الأداء، الفلاتر، والتفاعل بين الرسوم.

## 4. طبقات قاعدة البيانات

### Raw

نسخة من البيانات الأصلية. لا أعدلها حتى أستطيع الرجوع إليها ومقارنة نتائج
التنظيف بالمصدر.

### Clean

تحتوي النسخة المبسطة للمشروع على 6 Views:

| View | وظيفتها |
|---|---|
| `clean.branches` | تنظيف أكواد وأسماء الفروع والمواقع |
| `clean.products` | إزالة تكرار المنتجات وتوحيد اللون والمقاس والأسعار |
| `clean.customers` | تنظيف الهاتف والبريد وربط سجلات العميل المكررة |
| `clean.store_sales` | تنظيف مبيعات الفروع والتواريخ والأرقام وإزالة التكرار |
| `clean.online_sales` | تنظيف الطلبات الإلكترونية وربط الطلب بتفاصيل المنتجات |
| `clean.returns` | تنظيف المرتجعات وتصحيح مراجع سطور البيع عند الإمكان |

### Analytics

تحتوي النسخة المبسطة على 5 Views:

| View | وظيفتها |
|---|---|
| `analytics.dim_date` | تقويم يومي لعامي 2024 و2025 |
| `analytics.dim_customers` | سجل واحد لكل عميل بعد معالجة التكرار |
| `analytics.dim_products` | بيانات المنتجات المستخدمة في تقسيم المبيعات |
| `analytics.dim_locations` | بيانات الفروع والمواقع |
| `analytics.fact_sales_analysis` | جدول التحليل النهائي الذي يستخدمه Tableau |

إجمالي النسخة المعروضة في الـPortfolio هو **11 View فقط**. خطوات التنظيف
الداخلية مكتوبة كـCTEs داخل الـViews بدل إنشاء عدد كبير من الـViews الوسيطة.

## 5. ما معنى View وCTE؟

- **View:** استعلام SQL محفوظ داخل قاعدة البيانات، نتعامل مع نتيجته مثل جدول
  افتراضي.
- **CTE:** خطوة مؤقتة داخل الاستعلام تبدأ بكلمة `WITH`. تساعد على تقسيم
  الاستعلام إلى مراحل مفهومة، لكنها لا تنشئ View جديدة.

مثال الفكرة:

```sql
WITH cleaned AS (
    SELECT ...
    FROM raw.store_sales
)
SELECT *
FROM cleaned;
```

## 6. أهم مشكلات جودة البيانات التي تعاملت معها

- تواريخ مكتوبة بأكثر من صيغة.
- أرقام مالية تحتوي على فواصل أو كلمة `EGP`.
- سطور مبيعات وشحنات مكررة.
- اختلاف أسماء وأكواد الفروع.
- ألوان ومقاسات منتجات مكتوبة بصيغ مختلفة.
- أرقام هواتف مصرية بصيغ `20` و`0020`.
- سجلات متعددة لنفس العميل.
- معرفات ناقصة أو خاطئة لبعض سطور المرتجعات.
- اختلاف أسماء المحافظات بين العربي والإنجليزي.

## 7. جدول التحليل النهائي

`analytics.fact_sales_analysis` يجمع مبيعات الفروع والأونلاين في شكل واحد، ثم:

1. يربط كل عملية بيع بالعميل والمنتج.
2. يصنف الطلب إلى Recognized أو Open أو Cancelled.
3. يحسب المبيعات المعترف بها.
4. يضيف تكلفة المنتج.
5. يحسب تكلفة البضاعة المباعة والربح الإجمالي.

هذا هو الجدول الأساسي الذي استخدمته لبناء Dashboard في Tableau.

- مبيعات الفروع الستة متقاربة، وكل فرع حقق تقريبًا بين **18.6M و18.9M EGP**.
- المبيعات الشهرية مستقرة نسبيًا حول **6–7M EGP** مع بعض الارتفاعات المحدودة.

## 12. ما المطلوب فهمه قبل عرضه؟

لا تحتاج إلى حفظ كل سطر كود. ركّز على فهم:

1. لماذا احتفظنا بطبقة Raw؟
2. كيف أزلنا التكرار باستخدام `ROW_NUMBER()`؟
3. كيف وحّدنا التواريخ والأرقام والقيم النصية؟
4. لماذا دمجنا Store وOnline باستخدام `UNION ALL`؟
5. الفرق بين Total Sales وGross Profit وGross Margin وAOV.
6. لماذا استخدم Tableau جدول التحليل النهائي بدل الجداول الخام؟

عندما تستطيع شرح النقاط الست بطريقتك، ستكون قادرًا على عرض المشروع بثقة دون
الحاجة إلى حفظ الكود.
